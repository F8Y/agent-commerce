# Региональные магазины: Tilda и uniSiter

Проверено вживую 2026-10 (Хабаровск). Задача — понять, можно ли добавить товар
в корзину **без ручных кликов**, чтобы этим управлял ТГ-бот: пользователь пишет
текст, агент делает остальное.

Проверка 2026-10 заканчивалась на «товар в корзине + форма заказа доступна».
Сейчас агент отправляет форму, но только после подтверждения пользователя
кнопками в Telegram (`checkout-guard`); порядок — `SKILL.md` §4. Карточные
данные не вводим, онлайн-оплату не выбираем.

Машиночитаемый реестр четырёх проверенных магазинов (категории, `addToCart`,
селекторы) — `shops.json` в этой же папке. Здесь — детали и рецепты площадок.

## 2. Tilda Store — три проверенных магазина

Все три — Tilda Store с гостевой корзиной в `localStorage.tcart`. Добавление
работает только через `element.click()` из `eval`: CDP-клик по кнопке Tilda
часто не срабатывает. Универсальный алгоритм оформления — `SKILL.md` §4; ниже —
детали и проверенные селекторы.

| Магазин | Что продаёт | Кнопка «В корзину» | Checkout |
|---|---|---|---|
| **morekraba.shop** («Море Краба») | морепродукты, наборы, сертификаты | `a.t-store__prod-popup__btn` | только `#tcart` (не `/franchise`): имя, телефон, доставка, адрес, комментарий, упаковка, промокод, согласие |
| **myryba.ru** («Рыба моя») | рыба, морепродукты | `a.t-store__prod-popup__btn`, `a.t-store__card__btn` | только `https://myryba.ru/korzina`: имя, телефон, дата/время, улица, дом, подъезд, этаж, квартира, комментарий, согласие |
| **sayflowers.ru** («Скажи Цветами») | цветы, букеты, подарки | `a.t-store__prod-popup__btn` | попап корзины (`.t706__carticon`): имя, телефон, доставка/самовывоз, адрес и время, получатель, бонусная карта, согласие |

### 2.1. morekraba.shop

- Карточка товара открывается попапом; кнопка — `a.t-store__prod-popup__btn`.
- Проверено: JS-клик → тост «добавлено в корзину», `tcart` обновился.
- Корзина: `localStorage.tcart` (`products[]`, `amount`, `prodamount`, `total`).
- **Заказ оформляется только на `https://morekraba.shop/#tcart`.**
  `https://morekraba.shop/franchise` — заявка на открытие франшизы, не заказ:
  товары и сумма туда не попадают. Никогда не открывать её для оформления.
- Порядок:
  1. Открыть `https://morekraba.shop/#tcart`, дождаться загрузки.
  2. Проверить `JSON.parse(localStorage.getItem('tcart'))` — `products` и
     `prodamount` не нулевые.
  3. Форма уже открыта: `.t706__cartpage-form-wrapper form`. Кнопка
     `.t706__cartpage-open-form` скрыта, пока форма развёрнута.
     Признак правильной формы: есть поля `Адрес доставки_2` и `Комментарий`.
     Если видны `Способ связи` и `Input` — это `/franchise`, закрыть и открыть
     `#tcart` заново.
  4. Заполнить по `name`: `Имя`, `tildaspec-phone-part[]`, `Адрес доставки_2`
     (для доставки), `Комментарий`, при необходимости `Промокод`.
     Радио `Radio` — «Доставка по городу» (по умолчанию) или «Самовывоз из
     магазина»; радио `Упаковка` — «Крафтовый пакет» по умолчанию.
  5. Поставить галочку `Checkbox` (согласие) — по умолчанию снята, без неё
     форма не отправляется.
  6. Нажать `button.t-submit` внутри `.t706__cartpage-form-wrapper form`
     (текст «Оформить заказ»). Другие кнопки с тем же текстом относятся к
     другим формам.
  7. Успех — «Спасибо»/номер заказа, корзина очистилась. Ошибка или отсутствие
     реакции — не жать повторно, сообщить пользователю.
- Менеджер подтверждает по телефону; итоговая цена может измениться из-за
  веса/наличия.

### 2.2. myryba.ru

- Кнопка в карточке — `a.t-store__prod-popup__btn` (текст «Купить»); в
  каталоге — `a.t-store__card__btn`. `a.t-btn.js-store` на сайте нет.
- Проверено: JS-клик → тост, `tcart` обновился (горбуша 399 ₽).
- Корзина: `https://myryba.ru/korzina` (в меню ссылка «Корзина», href
  `#opencart`). Иконка корзины в шапке скрыта настройками сайта.
- Форма уже развёрнута: `.t706__cartwin .t706__orderform form`. Поля по
  `name`: `tildaspec-phone-part[]`, `Name`, `Дата_доставки` (ДД.ММ.ГГГГ),
  `Время доставки` (ЧЧ:ММ), `Улица`, `Дом`, `Подъезд`, `Этаж`, `Квартира`,
  `Комментарий` (textarea), `Checkbox` (согласие — поставить).
- Кнопка отправки — `button.t-submit` внутри той же формы, текст
  **«Оформить»**. Другие кнопки «Оформить»/«Отправить» на странице относятся
  к скрытым формам («Перезвоните мне» и др.) — не трогать.
- Доставка: до 5 000 ₽ курьера заказывает и оплачивает клиент; от 5 000 ₽ —
  бесплатно курьером Яндекса по Хабаровску. Подтверждение — звонком, весовая
  продукция может изменить итог. Отправку не нажимали.

### 2.3. sayflowers.ru

- Рейтинг 5.0 (5 472 оценки в 2ГИС) — лучший из проверенных цветочных.
- Карточка: `/catalog/<раздел>/tproduct/<id>-<slug>`.
- **Варианты товара.** У части букетов в карточке
  (`.t-store__product-snippet`) есть выбор:
  - количество — радио `input[type=radio][name="Количество"]`, значения вида
    «9 веток», «11 веток», «19 веток», «25 веток» (по умолчанию первый);
  - доп. опции — `select` без `name`: «Добавить открытку?» («Нет» /
    «Да (55 руб)») и «Добавить транспортировочную коробку?» («Нет» /
    «Да (440 руб)»).
  Цена пересчитывается после выбора; читать её в
  `.t-store__product-snippet .js-store-prod-price-val`. Радио выбирать
  `browser_click` по тексту, `select` — `browser_select_option` со значением,
  равным тексту опции.
  Пример «Букет нежных гвоздик»: 9 — 1 770 ₽, 11 — 2 090 ₽, 19 — 3 535 ₽,
  25 — 4 495 ₽; +55 ₽ открытка, +440 ₽ коробка. В корзине выбор лежит в
  `products[].options[]`, а `name` остаётся «Букет нежных гвоздик»; при
  19 ветках + открытке `amount = 3 590 ₽`.
- Кнопка — `a.t-store__prod-popup__btn`; проверено на «Композиция в мини
  тыкве»: тост «добавлено», `tcart.prodamount = 2 800 ₽`.
- **Страницы корзины нет.** Корзина — попап `.t706__cartwin`. Открывать
  иконкой: `document.querySelector('.t706__carticon').click()` (иконка видна,
  когда корзина не пуста).
- Форма: `.t706__cartwin .t706__orderform form` (класс `t-conditional-form`).
  Поля появляются по выбору:
  1. `Имя`, `tildaspec-phone-part[]` — заказчик.
  2. `delivery`: «Да (рассчитать стоимость доставки)» или «Нет, заберу в
     магазине (бесплатно)».
  3. Доставка → `delivery_address`, `Комментарий к заказу`,
     `Когда доставить заказ?*` (дата), радио `Выберите время доставки*`
     (09:00–21:00; «точное время» ×2 и «нерабочее время» 1000 ₽ — платные).
     Самовывоз → `Дата самовывоза`, `Время самовывоза`.
  4. `Получатель`: «Я» / «Другой человек» (для второго — `Имя получателя`,
     второй `tildaspec-phone-part[]`, `Не предупреждать получателя`).
  5. `Бонусная` → «Не зарегистрирован(а), и не хочу проходить регистрацию».
  6. `Согласие на обработку ПД` — поставить.
- Кнопка отправки — `button.t-submit` внутри формы, текст
  **«Отправить заявку»**. На странице есть другие кнопки «Отправить» (квиз,
  заявка) — жать только кнопку внутри `.t706__cartwin`.
- Отправку не нажимали.

### 2.4. Общий алгоритм для Tilda

Признаки: `tilda-cart`, `t-store`, `js-store-product`, `localStorage.tcart`.

1. Открыть каталог, найти карточку товара (`/catalog/.../tproduct/...`).
2. Открыть страницу товара.
3. Нажать кнопку **из eval**, не CDP-кликом:
   ```js
   const b = [...document.querySelectorAll('a, button')]
     .find(x => /^\s*(в корзину|купить)\s*$/i.test((x.innerText || '').trim()));
   b.click();               // именно element.click()
   ```
4. Прочитать корзину:
   ```js
   JSON.parse(localStorage.getItem('tcart') || '{}')
   // products[], amount, prodamount, total, delivery
   ```
5. Проверить, что `products.length` вырос и в тосте есть «добавлено в корзину».

Особенности:
- Корзина живёт в `localStorage`, поэтому привязана к профилю браузера.
- Очистка тестовой корзины:
  ```js
  localStorage.removeItem('tcart');
  localStorage.removeItem('tcart_discounts');
  ```
- Перед добавлением читать `tcart`: на Tilda повторный клик обычно увеличивает
  количество, а не заменяет позицию.

## 3. uniSiter (пример: shop.fcska.ru, ФК «СКА-Хабаровск»)

Признаки: `/engine/public/`, `/kernel/js/`, `shop_current/shop.js`, `cartVersion`.

### Добавление

На странице товара основная кнопка — внутри формы:

```html
<form class="forms" action="./ajax_buy.php" method="post" data-form-name="AddToCart">
  <input type="hidden" name="goods_id" value="150">
  <input type="hidden" name="action" value="buy">
  ...
  <div id="buy_btn_cont"><input type="submit" value="Купить"></div>
</form>
```

Клик:

```js
document.querySelector('form[action$="ajax_buy.php"] #buy_btn_cont input[type=submit]').click();
```

Грабля: в блоках «похожие товары» тоже есть `input.buy[data-goodsSubId]`, и они
идут в DOM **раньше** основной кнопки. Если кликнуть первый `.buy`, в корзину
попадёт товар из рекомендаций, а не текущий. Основную кнопку брать только из формы
`ajax_buy.php`.

Проверка результата:

```js
// счётчик в шапке
document.getElementById('cart').innerText           // "1\nОформить заказ"
// AJAX-фрагмент корзины
await (await fetch('/shop/cart.php?ajax')).text()   // <strong>1</strong>
// JSON со суммой
await (await fetch('/shop/ajax_cart.php')).text()   // {"sum":2450,"count":1,...}
```

### Корзина и заказ

`/shop/cart/` доступна **гостю**. Форма:

| Поле | Смысл |
|---|---|
| `login` | имя |
| `phone` | телефон (маска `+7 (___) ___-__-__`) |
| `mail` | e-mail |
| `address` | адрес доставки |
| `extra` | комментарий |
| `delivery_city`, `citySelect`, `post_code` | город и индекс |
| `payment` | радио: карта / наличные / оплата на сайте |
| `delivery` | радио: самовывоз (ул. Карла Маркса, 60/2) |

Корзина серверная, привязана к cookies — нужен постоянный профиль браузера.

Удаление тестовой позиции: ссылка «Удалить» на `/shop/cart/`.

## 4. Выводы для ТГ-бота

1. **Tilda** — самый переносимый вариант: корзина в `localStorage`, добавление
   одним `element.click()`, checkout — текстовая форма. Проверены
   morekraba.shop, myryba.ru, sayflowers.ru.
2. **uniSiter (СКА)** — тоже полностью автоматизируется, включая гостевую форму
   заказа. Один магазин, но с реальным checkout.
3. Перед добавлением всегда читать корзину: повторный клик увеличивает количество.
4. После проверок очищать тестовые корзины (Tilda — `localStorage`, uniSiter —
   «Удалить» на `/shop/cart/`).
